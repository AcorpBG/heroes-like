## Implemented correction

The source problem was authored scene-layer placement, not texture import or build-state resolution. All 32 town catalogs use six village paintings; layers were positioned as if some painted roofs, river bends and cliff faces were empty ground. Independent plots also buried each other's entrances. The shared cover-crop projection and alpha-aware building controls were already correct.

61 manifest rows now have revised aspect-preserving bounds and ground landmarks: Embercourt 14, Mireclaw 6, Sunvault 12, Thornwake 9, Brasshollow 11, Veilmourn 9. Only `normalized_rect`, `ground_anchor` and their grounding descriptions change. Original raster bytes, paths, provenance, catalog/upgrade identities and gameplay rules are unchanged. Paired base/upgrades keep their shared site.

Pointer testing exposed an additional input defect: the high-priority village main-building rectangles in Mireclaw, Veilmourn and Sunvault extended beyond the actual hall/pavilion into adjacent building plots. Their bounds now follow the main building, preserving construction-ledger routing while allowing Reed Toll, chapel/salvage and Parallax clicks. Other factions/stages and input ordering are unchanged.
