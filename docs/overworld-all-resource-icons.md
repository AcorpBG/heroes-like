The current footer exposes a gold/wood/ore summary or a compact Stores button, although its popup already lists all nine live resources. ## Implementation and evidence

The old Overworld button used `describe_resources`, which omitted zero rare holdings, and its constrained footer allocation could collapse the summary to `Stores`. The popup already had every currency; missing economy data was not the cause.

The authored scene now places a thin, full-width resource strip above the commands. `enable_inline_icons()` opts only Overworld into nine registry-backed icon/quantity cells: gold, wood, ore, aetherglass, embergrain, peatwax, verdant_grafts, brass_scrip and memory_salt. Icons reuse the popup's original `content/resources.json` art resolution. Zero holdings remain visible; large quantities abbreviate, with exact quantities and full names in tooltips and the keyboard/pointer-accessible popup. Refreshing the stockpile updates every cell without mutating the session. Resource-gain feedback sits beside holdings, not over them. Town retains its existing shared-menu presentation.
