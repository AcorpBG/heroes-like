# Built-building silhouette outlines

Owner-directed Phase 6 slice `ui-town-building-silhouette-outlines-20260911`, completed 2026-09-11.

Constructed scenic buildings already use alpha-aware `TownBuildingHotspot._has_point`, but TownStageView assigns rectangular StyleBoxFlat hover, pressed and keyboard-focus decoration. Replace that decoration with an exterior silhouette derived from the same painted mask. Keep a visible, consistent screen-space focus stroke, transparent background, original texture/crop projection, click behavior and accessible labels. Cache source contours when the painted mask changes; do not read textures, rebuild contours or poll every frame for highlights.

Scope: the 173 constructed scene-layer building rasters, including upgrade variants. The embedded background main-town building's separate construction-ledger hotspot is not a constructed raster layer and remains unchanged in this slice. No new art, asset processing, building placement changes, gameplay/balance/save changes, RMG or unrelated UI redesign.

Implementation owners: `scenes/town/TownBuildingHotspot.gd`, `scenes/town/TownStageView.gd`; Python-owned regression under `tests/`. Completion requires mask-derived nonrectangular contours for every layer, transparent-corner and cropped projection controls, hover/pressed/focus visual inspection at 1280x720 and 2048x1079, unchanged Town build/save/input regression, repository validation, Linux/Windows export/package checks, scoped cleanup and coherent commit/push. Reports alone do not complete this slice.

## Implementation and evidence

`TownBuildingHotspot` now owns empty theme styles in all button states and traces its existing alpha BitMap into closed, normalized source contours. The cache changes only when the mask identity changes and is first populated on highlight. Drawing maps those contours through the exact `texture_region_ratio` and control size used by alpha hit testing; Control clipping prevents cropped-away segments from escaping. Hover uses a thin gold stroke, focus/press a stronger pale-gold stroke, both with a subtle dark contrast edge and no rectangular fill. `TownStageView` no longer overwrites those styles and requests a redraw after projection updates. No new texture resources, frame polling, art edits, placement changes or gameplay changes.

`tests/town_building_outline_regression.py` extends the existing all-town regression: all 173 masks produce closed nonrectangular contours; all six theme states are empty; unchanged-mask reuse, crop projection, actual hover, keyboard focus, information clicks and complete view-state purity are checked. It retains all 32 ordinary paid-build/full-rule-control/save-resume cases. Each faction has normal/hover/focus/pressed renderer captures. The `crop-control` image deliberately changes only UV projection to test clipping; it is a synthetic control, not normal gameplay or new building placement.
