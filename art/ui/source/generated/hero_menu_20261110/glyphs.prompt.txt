A sprite sheet of twelve small interface icons for a fantasy strategy game, on a fully transparent background. The icons sit in a strict grid of four columns and three rows, evenly spaced, each icon centred in its own cell with wide empty transparent space around it, all the same size, none touching another. No text, no letters, no numbers, no frames, no grid lines, no background shapes.

Style, the same for all twelve: engraved antique-gold emblem, a clean bold gold outline drawing with a little warm cream highlight and a little dark bronze shading, flat-on, readable at 32 pixels, like the glyphs of a heraldic game interface.
