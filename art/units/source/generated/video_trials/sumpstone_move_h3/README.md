# Sumpstone Guards H3 movement

`unit_neutral_sumpstone_guards`: 20 observed frames, source indices 40–78 every second frame, form a reciprocal armored walk. Runtime timing is 65 ms per frame (1,300 ms), deliberately faster than the approximately 1,667 ms source cycle. The two boots alternate forward contact and passing while the pick grip, rigid crystal shield, red beard and cyan headlamp retain their identity. No reversed, duplicated or interpolated poses were added.

The unit's original `move_contacts_v2_00.png` and `move_contacts_v2_01.png` paintings supply the endpoints and frame-61 guide. Exact rectangles, anatomical anchors and hashes are in `reference.json`. Both use input scale 0.50 on a 960×544 canvas with anchor (480,490). Extraction scale 0.212/0.50 matches the accepted idle/attack anatomy; it does not retain the oversized legacy movement. No per-frame alignment or size normalization is applied.

Pure green protects the violet/cyan equipment. `produce.py` checks the four corner colors, unmixes green and removes disconnected faint plate residue while retaining opaque-connected thin edges. Enlarged light/dark samples and all 124 chronological source frames were inspected, followed by the Godot battle-scale overview. The 116 candidate and 130 published focused Windows checks passed. All 40 poses from the six earlier accepted actions preserve pixels, offsets and timing; map idle is byte-identical. This was not a continuous playback review, manual game playtest, full-suite run or Linux validation.

Generation used the recorded local MiniMax H3 graph, seed 2026092414, 20 steps and 124 frames at 24 fps.
